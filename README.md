# Spellbook
An Obsidian theme designed to make Obsidian feel like writing in a spellbook.

> [!INFO]
> Compatible with **Syle Settings** plugin

> [!WARNING] Themes
> Spellbook does have a light theme but it is designed with the use of dark theme in mind, therefore the light theme has farily low contrast.

## Colours
The colours are mostly based off Obsidians default theme, but the dark theme has much darker background colors

Any non-neutral colour uses your accent, or variants of your accent colour.

## Animations
Spellbook uses some animations on the openings of tabs

## Style Settings
List of controls available with **Style Settings**  community plugin.
+ Spellbook's font
+ Where Spellbook's font is applied
+ The speed animations (including whether they play or not)
+ Which icon that is used as a detail in the editor
+ Whether that icon displays
